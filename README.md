# Lobe Activation Trainer

Single-page stimulus display for the FNS "Lateralization & Lobes" practice session.
Pick a hemisphere and a cortical region; the page shows the matching on-screen task.

Source of truth: `FNS/outputs/lateralization_practice_2026-10-19/app/lobe_activation_trainer.html` (copied here as `index.html`).
